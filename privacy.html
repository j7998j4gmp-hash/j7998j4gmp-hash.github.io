Privacy Policy

Last updated: November 23, 2026

Purpose

JQuants Stock Data is a personal application for storing Japanese stock market data in the user's Google Drive.

Google Drive Access

The application requests Google Drive access to create and manage files used for stock market data storage.

Data Handling

Stock market data is stored in the authorized user's Google Drive. OAuth credentials are intended to be stored securely in GitHub Actions Secrets.

Data Sharing

The application is intended for personal use and does not intentionally share Google user data with third parties.

Revoking Access

Users can revoke access through their Google Account security settings.
